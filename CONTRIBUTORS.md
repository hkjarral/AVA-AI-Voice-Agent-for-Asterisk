## How to Get Added

Your name is added here when your first PR is merged. All contribution types are recognized — code, docs, tests, configs, case studies, ideas, and bug reports.

Contributor avatars/badges appear in the [main README](README.md#contributors).
If your GitHub handle changes or your credit is missing, open an issue or PR with
a link to your merged contribution. Historical credit corrections do not imply
those changes are new in the current release.

## Want to Contribute?

See [Contributing](CONTRIBUTING.md) for code and non-code ways to help, and the
[Developer Documentation](docs/contributing/README.md) for technical guides.
