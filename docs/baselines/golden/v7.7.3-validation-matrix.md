## Security assessment

The cutoff retains patched `msgpack 1.2.3` and `dnspython 2.9.2`, and the CPU
Local AI Dockerfile enforces the fixed Trixie `zlib1g` package. The most recent
applicable [main dependency scan](https://github.com/hkjarral/AVA-AI-Voice-Agent-for-Asterisk/actions/runs/42961870879)
at `9fd9eeaa` contains neither the two targeted Engine advisories nor the three
CPU Local AI zlib findings from the v7.7.2 preparation. This is historical scan
evidence. Scan the final release branch and inspect its SARIF before publication.
The standard scan filters findings without fixes and uses the CPU core profile.

GitHub's dependency-alert snapshot on 2026-11-13 has 39 open alerts, comprising
4 critical, 9 high, 18 medium and 8 low. This broader manifest baseline differs
from the image scan. Remaining alerts include optional Torch/Transformers model
loading, Monaco's DOMPurify dependency and Admin's `python-jose` dependency.

- The [python-jose advisory](https://github.com/advisories/GHSA-3qf3-8w2g-rqmx)
  concerns asymmetric public keys accepted as HMAC secrets. AVA's authentication
  code restricts decoding to HS256 and uses the configured symmetric secret.
  That is evidence against this specific algorithm-confusion path in the shipped
  configuration. It does not dismiss the package alert for other consumers.
- The [DOMPurify advisory](https://github.com/advisories/GHSA-cg2g-xh64-v4q7)
  requires template-safe mode with DOM-returning/in-place processing and a
  shadow-root input. AVA has no direct DOMPurify calls in its application sources;
  transitive Monaco use needs explicit assessment before a clearance claim.
- Model-loading alerts remain relevant to installed optional backends and the
  artifacts they load. Preserve the trusted-model policy and document selected
  backends when assessing exposure. A CPU core scan does not qualify every
  optional CPU/GPU backend.

### Bookworm publication decision

Engine, Admin UI and updater still use Debian Bookworm bases. The
[v7.7.2-only exception](v7.7.2-validation-matrix.md#bookworm-exception-for-v772)
covered `zlib1g 1:1.2.13.dfsg-1`. Debian still lists the package as affected by
[CVE-2026-76844](https://security-tracker.debian.org/tracker/CVE-2026-76844),
[CVE-2026-85091](https://security-tracker.debian.org/tracker/CVE-2026-85091), and
[CVE-2026-27171](https://security-tracker.debian.org/tracker/CVE-2026-27171).
That prior approval is historical. Recheck actual image packages and available
vendor fixes; record remediation or obtain a fresh maintainer disposition before
tagging v7.7.3. No v7.7.3 security exception is claimed here.
