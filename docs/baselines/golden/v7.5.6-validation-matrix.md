## Compatibility and rollback boundary

- v7.5.6 is an in-place release with no database downgrade step.
- Existing Agents inherit global hangup markers until explicitly changed.
- Existing summary-enabled webhooks without `summary_provider` retain the
  legacy OpenAI summary path.
- Explicit summary providers fail closed for summary generation but the
  webhook still executes with an empty `{summary}`.
- Pause campaigns before upgrade or rollback. Application rollback uses the
  v7.5.5 images and the pre-update operator configuration backup; restore that
  backup if v7.5.6-only Agent or webhook fields were configured. The updater
  records the pre-update running-service set so partial-failure rollback
  restores previously running services without starting absent or stopped
  optional Local AI deployments.
