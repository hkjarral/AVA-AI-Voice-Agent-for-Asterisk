## Upgrade, rollback, and compatibility boundary

- v7.6.1 has no database migration and does not change saved provider, Agent,
  transport, Audio Profile, or transfer-destination selections.
- Fish Audio is opt-in. HTTP remains its default transport; realtime WebSocket
  text streaming is enabled only when that Fish Audio provider is configured for
  it. Existing TTS adapters retain the fragment-by-fragment path.
- Rebuild and recreate `ai_engine` and `admin_ui`. The bundled
  `local_ai_server` is unchanged.
- Deferred transfers now treat an unsuccessful caller-facing drain as
  authoritative and fail closed. A custom drain ceiling remains configurable;
  the default is 15 seconds.
- Rollback requires no database downgrade. Drain calls and restore the v7.6.0
  configuration backup before starting v7.6.0, especially when Fish Audio or
  v7.6.1-only transfer settings were added; older strict schemas may reject
  unknown provider types or fields.
- PR #670 is the only dependency update in this release cutoff. Other open
  Dependabot PRs are intentionally deferred to a later cohesive batch.
