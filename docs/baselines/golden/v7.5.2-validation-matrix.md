## Compatibility and rollback boundary

Use `wideband_pcm_16k` only with AudioSocket, Asterisk 20.17+, 21.12+, 22.7+,
or 23.1+, and an endpoint or SIP trunk leg that actually negotiates a wideband
codec such as G.722. ExternalMedia RTP and PSTN/G.711 routes remain on
`telephony_ulaw_8k` or `telephony_enhanced_8k`.

Rollback requires no database migration or provider-template edit: assign the
Agent back to an 8 kHz Audio Profile and apply the configuration.
