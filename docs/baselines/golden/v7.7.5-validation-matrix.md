The seven current manifest alerts remain **1 critical, 3 medium and 3 low**.
No dependency manifest changed since v7.7.4. The auth, image copy boundary and
unchanged Monaco configuration were rechecked against current source. Scanner
counts are package/advisory/configuration results, not unique CVE counts. The
new compressed-data disclosure requires an attacker to supply input and observe
output; indirect native-library consumers are not proven unreachable by a source
search. Trusted model/archive inputs remain necessary, not a substitute for a fix.

Reassess actual authentication, sanitizer, development-tool, archive/model input
and management-access paths before proposing a release-only disposition. Retain
private management/dev servers, strong private symmetric secrets, current
sanitizer modes and trusted package/model/archive inputs; controls are not a
remediation claim. New findings require their own assessment. No Dependabot PR
or dependency is modified by this preparation.
