## Compatibility and rollback boundary

- v7.5.4 is an in-place patch release with no database downgrade step.
- Disabling diagnostics prevents new writes but never deletes historical WAVs.
- Deepgram custom/private model values remain visible, but AAVA claims support
  only for the documented telephony-focused surface. Unknown or mismatched Aura
  voices fail before connection.
- A stopped optional Local AI service remains stopped through update and
  rollback; an absent unselected service remains absent.
- Application rollback uses the prior tagged images and the pre-update operator
  configuration backup. Remove diagnostic artifacts separately according to the
  deployment's retention policy.
