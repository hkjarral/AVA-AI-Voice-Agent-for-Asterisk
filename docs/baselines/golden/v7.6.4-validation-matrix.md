## Compatibility and security baseline

Follow [v7.6.3 to v7.6.4 migration](../../MIGRATION.md#v763-to-v764) and the
[upgrade/recovery guide](../../INSTALLATION.md#upgrade-to-v764-existing-checkout).
Review HTTP body formats, single-pass substitution, protected context and URL
components before rollout. The Admin HTTP preview is a separate implementation.
Google marker heuristics remain opt-in and ambiguous phrases remain a risk.
Custom automatic FastAPI telemetry requires the documented SDK/exporter extra
and opt-in environment flag; standard deployments require neither.

The preparation security snapshot has 33 open dependency alerts: 3 critical,
8 high, 15 medium and 7 low. #740 documents the held model/runtime dependencies
and unpatched braces/python-jose baseline. No alerts are dismissed and this is
not a claim that all dependency security issues are cleared. Keep follow-up work
in the existing dependency tracking record; do not mutate open dependency PRs.

Rollback restores older code behavior, including the pre-fix HTTP renderer;
restrict affected tools if rollback is necessary. Preserve remote side effects
and reconcile ambiguous results before retrying.
