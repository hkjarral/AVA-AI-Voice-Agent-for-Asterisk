## Security

The most recent applicable [Trivy engine scan](https://github.com/hkjarral/AVA-AI-Voice-Agent-for-Asterisk/actions/runs/42350415670)
ran on `6c000842` after the A2A SDK dependency change. Its engine SARIF includes
both advisories below. The cutoff still has the same dependency pins. A scan on
the eventual release candidate is a separate gate.

| Advisory | Candidate and exposure |
| --- | --- |
| [CVE-2026-114605](https://github.com/rthalley/dnspython/security/advisories/GHSA-45c3-73f7-pv4m) | `dnspython 2.8.0` remains below the 2.9.0 fix. Transcript email domain validation is off in shipped config and was off in the earlier read-only voiprnd check. Deployments enabling it can reach the DNS parser. |
| [CVE-2026-114613](https://github.com/msgpack/msgpack-python/security/advisories/GHSA-j586-36cw-2gc2) | `msgpack 1.2.1` remains pinned. Trivy flags it, while upstream confirms reproduction on 1.2.2 and leaves the earliest affected release uncertain. The earlier read-only voiprnd check found an active Fish Audio Agent using the C decoder via provider WebSocket. The HTTP default bypasses this decoder. The 1.2.3 fix is proposed in [#788](https://github.com/hkjarral/AVA-AI-Voice-Agent-for-Asterisk/pull/788). |
