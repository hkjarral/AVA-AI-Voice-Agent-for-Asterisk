## Security

The [security PR scan](https://github.com/hkjarral/AVA-AI-Voice-Agent-for-Asterisk/actions/runs/42553010662)
cleared the two targeted Engine findings and three CPU Local AI findings from
the [earlier release PR scan](https://github.com/hkjarral/AVA-AI-Voice-Agent-for-Asterisk/actions/runs/42548263433).
Built `linux/amd64` images verified `msgpack 1.2.3` with the C decoder,
`dnspython 2.9.2`, and the fixed Debian Trixie `zlib1g` package in CPU Local AI.
The dependency update passed 103 focused tests and offline Fish Audio decoder
and DNS wire smoke checks. Two credential-dependent Fish Audio API tests were
skipped. The `dnspython` update also addresses the upstream
[zone-file advisory](https://github.com/rthalley/dnspython/security/advisories/GHSA-vvf4-9x63-8xvv).

### Bookworm exception for v7.7.2

The Engine, Admin UI and updater images still include Bookworm `zlib1g`
`1:1.2.13.dfsg-1`. Their configured Debian repositories offered no newer
candidate during verification. The Debian tracker lists Bookworm exposure for
[CVE-2026-76844](https://security-tracker.debian.org/tracker/CVE-2026-76844),
[CVE-2026-85091](https://security-tracker.debian.org/tracker/CVE-2026-85091) and
[CVE-2026-27171](https://security-tracker.debian.org/tracker/CVE-2026-27171).
Direct reachability through AVA was not established. The standard Trivy workflow
filters findings without fixes, so a green scan does not clear these advisories.

The maintainer approved carrying this residual risk for v7.7.2 only, conditional
on green release-candidate checks. Keep Admin UI and Docker management interfaces
on trusted networks. Release maintainers will recheck vendor package availability
and image-base remediation by 2026-11-16 or before the next stable tag, whichever
comes first. The Trixie CPU Local AI image carries the vendor fix.
