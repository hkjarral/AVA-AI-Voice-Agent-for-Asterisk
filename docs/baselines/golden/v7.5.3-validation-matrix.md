## Known issue

GitHub issue [#585](https://github.com/hkjarral/AVA-AI-Voice-Agent-for-Asterisk/issues/585)
tracks an Admin UI-only Docker readiness false-negative: the shipped Docker SDK
7.0.0 adapter is incompatible with Requests 2.33.0 and can show **Action Required**,
`Docker: --`, and an incorrect **Install Docker** action after a clean rebuild.
The Docker socket, Compose, containers, call engine, providers, pipelines, and
models remain operational. Operators must not reinstall Docker when those direct
checks are healthy.

## Compatibility and rollback boundary

Audio recovery is explicitly scoped to audio encoding, rate, format, and resampler
fields. It does not reset credentials, models, voices, prompts, provider identity,
Agent assignments, or pipeline composition. Existing values remain unchanged until
an operator chooses a restore action.

The release has no database rollback. Restore the prior tagged images and local
configuration backup if application rollback is required. An indeterminate transfer
continuation intentionally retains transfer ownership; cleanup must not reclaim a
caller leg that Asterisk may already have accepted.
